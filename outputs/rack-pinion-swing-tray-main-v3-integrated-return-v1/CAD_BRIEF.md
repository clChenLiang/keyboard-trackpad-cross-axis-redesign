# V3 integrated return — CAD brief

- Units: millimetres.
- Coordinates: X left/right, +Y toward the display, +Z upward.
- Source policy: import the existing V3 and optional torsion cartridge; do not modify or overwrite either directory.
- Motion retained: keyboard travel `+20.42 mm` in Y and `-15.0 mm` in Z; vertical-shaft swing follows the existing approximately 90-degree mapping.
- Rack retention: two 6 mm OD, 24 mm long back-pressure rollers tangent to the rack back face. Their axes are perpendicular to the YZ travel vector. The rear roller is carried by a twin-leaf compliant mount; spring rate is intentionally not finalized.
- Return: bottom-mounted coaxial torsion cartridge is a standard assembly component and winds as the mechanism moves from keyboard mode toward trackpad mode.
- Excluded: endpoint detents, production tolerances, strength/fatigue analysis, BOM, STL/3MF, and continuous-pose collision reporting.
- Primary outputs: keyboard, midpoint, trackpad, and cylinder/return exploded STEP assemblies.
