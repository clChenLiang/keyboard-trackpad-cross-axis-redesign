# V3 可替换竖轴同轴扭簧回位模块 V1

本目录完全独立于 `rack-pinion-swing-tray-main-v3/`。单位 mm；沿用 V3 坐标，X 左右、+Y 朝显示器、+Z 向上。

## 定位与边界

- V3 原 Ø38 圆筒内没有可用的连续弹簧包络：小齿轮占 Z=26–48，上下轴承座占 Z=19–24 / 49–54，硬限位与摆臂占 Z=54–60.5。
- 因此本概念采用底座下方的可拆同轴底杯，不改变齿轮、轴承、推力接口、硬限位及悬臂位置。
- 模块包括：固定安装杯/锚环、三螺钉可拆底盖、真实螺旋扭簧实体、杯壁固定端锚孔、三组预紧调节孔、Ø8 轴的转动端夹持套及真实捕获槽、独立传扭键、三孔安装法兰。
- 不定最终簧率、簧丝、预紧力、强度或疲劳；不增加 0°/90°锁止。

## 概念参数

- 安装杯：Ø34 开底壳，主体 Z=-11…1，顶法兰 Z=1…3；可拆底盖 Z=-13…-11。拆盖后 Ø23 开口可装入 Ø20.2 弹簧和 Ø13 夹套；底座原底面 Z=3。
- 概念弹簧：线径 1.2、中心线直径 19、约 4.5 圈、有效高度约 8.1。
- 转动夹持套：Ø13，适配 Ø8 轴；通过独立矩形键与长轴传扭，并在相反侧用径向捕获槽承接弹簧动端；随 V3 竖轴从键盘态 0° 转到妙控板态约 90°。
- 三个 M3 名义安装孔位于 Ø27 分布圆；三个固定端预紧孔沿锚环分布。
- 安装版用 18 mm 高独立加高脚替换原脚；桌面基准 Z=-15，底盖最低 Z=-13，保留 2 mm 概念净空。

## 安装 V3 时必须采用的接口变化

这些变化只出现在本目录派生的“with optional return” STEP，V3 文件不被编辑：

1. 将原 Ø8×46 竖轴替换为向下延伸的 Ø8 长轴；
2. 在底座轴线上增加 Ø10 通孔；
3. 在底座增加三处 M3 安装孔；
4. 用加高底脚替换原 3 mm 底脚，为底杯提供桌面净空。
