# V11 首件打印与实体验收

数字验证已覆盖 401 个运动采样点和 101 个精确碰撞姿态，但首件循环仍是投入使用前的必做项。

## 打印前

- [ ] 先打印 `printables/calibration_coupon.*`，确认 604ZZ、MR84ZZ、偏心套和 M4 热熔螺母配合。
- [ ] 在切片软件中确认六张 3MF 保持多对象结构；不要自动合并相交物体。
- [ ] PETG-HF 与 TPU 95A 分开打印；按 `PRINT_SETTINGS.md` 设置壁数、填充和支撑。
- [ ] 弹簧供应商书面确认 BOM 中的刚度、压并长和 ±10% 刚度公差。

## 空载装配

- [ ] 左右框固定后四脚同时着地，侧框无肉眼可见内八/外八。
- [ ] 12 个轴承外圈均能转动，螺母只夹紧内圈。
- [ ] 左右交叉滚轮均接触长槽相对壁，不晃动、不夹死。
- [ ] 两根 Ø3 × 122 导杆到底，弹簧套在一体导套外且全程不屈曲。
- [ ] 右侧四个 0.6 mm TPU 浮动垫片已装，左侧无浮动垫片。

## 空载循环

- [ ] 慢速完成 20 次全行程，左右端同步。
- [ ] 中间任意位置松手，能连续返回键盘端位。
- [ ] 两端由 TPU 环限位；轴承不撞槽端。
- [ ] 无弹簧擦碰、轴承拖滑、异响或明显偏磨。

## 带载循环

- [ ] 放入实际键盘与妙控板后完成 100 次慢速全行程。
- [ ] 实测最大按压力建议在 16–23 N；明显超出时先检查偏心预紧与弹簧批次。
- [ ] 妙控板终态能到右手区，键盘托不妨碍手部抬升。
- [ ] 100 次后复查 M3 螺母、M4 螺钉、热熔螺母和 TPU 环，无松动或位移。

任一项失败即停止使用，记录失败姿态、左右侧、接触位置和弹簧批次后再修改 CAD；不要靠增大偏心预紧掩盖几何干涉。
