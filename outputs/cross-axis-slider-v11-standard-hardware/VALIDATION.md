# V11 验证方法

- 运动学：401 点检查交叉约束闭合、单调性与槽端余量。
- 碰撞：101 点覆盖 0%–100% 行程，每点由独立 OpenCascade 进程重建装配并做禁配运动组求交。
- 并行：最多 3 个隔离进程；单点 180 秒超时。任何超时、内核退出或无效 JSON 都按碰撞失败记录。
- 弹簧：用完整参数计算刚度一致性、Wahl 修正剪应力、安全系数、回位力、最强批次按压力和压并余量。
- 弹簧碰撞：使用包围完整 OD 和压缩长度的实心圆柱包络；它比展示用螺旋实体更保守。
- 其他：检查稳定裕量、首阶托盘强度、接口连接、单实体有效性、H2D 包络和排盘对象重叠。

权威结果见 `validation_report.json`。当前报告：101 个碰撞姿态、0 碰撞；六张打印板均无对象包围盒重叠。
